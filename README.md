# Timeless Beauty Raritan — Luxury Spa & Permanent Makeup Website

Modern, elegant, luxury aesthetic website for **Timeless Beauty Raritan** located in Raritan, NJ. Crafted with high-end UX/UI standards and full responsiveness across mobile, tablet, and desktop.

Designed by **[Easy Marketing](https://easymarketingus.com)**.

## ✨ Key Features
- **Official Brand Aesthetics**: Color palette harmonized with the official black & red logo (warm alabaster cream, ruby rose, luxury onyx, champagne gold).
- **Interactive Gold & Rose Dust Sparkles**: Ambient particle canvas in Hero section drifting upwards gently with automatic power saving.
- **Scroll Indicator Animation**: Animated drop-line and text prompting user exploration.
- **Infinite Running Marquee Ticker**: Highlights key salon credentials (5.0 ★ rating, licensed master artist Leena Tran, service overview).
- **Automated Entry Promotion Popup**: Displays special $350 Microblading / Ombré Brows voucher on site arrival with one-click code copy and direct booking integration.
- **Compact Feedback Carousel**: Interactive, space-saving review slider with touch/swipe mobile support, auto-play, pause on hover, and dot pagination.
- **Interactive Service Filter Menu**: Browse eyebrows, eyeliner, lips, and plasma lift with transparent pricing.
- **High-Resolution Lightbox**: Click any treatment portfolio item to view enlarged before-and-after results.
- **Mobile-First Sticky Action Bar**: One-touch Call, Google Directions, and Instant Booking.

## 🚀 Deployment
This is a static web application (HTML5, CSS3, Vanilla JS). It requires no build step and can be deployed directly to:
- **Vercel**: Import repository and deploy in 1 click.
- **Netlify**: Drag & drop or connect repository.
- **GitHub Pages**: Settings > Pages > Source `main` branch.
